This preserves PostgreSQL 18.6, direct parameterized SQL and the single-service architecture. There is no existing pg application code or persisted schema to migrate. ## Mandatory adapter profile

Explicitly construct all connection fields from validated installation configuration. Require verified TLS, trusted CA/hostname and SCRAM channel binding; reject plaintext and permissive TLS strings. Never pass a caller-provided URL or spread configuration. No debug logger, notices, tracing subscriber, subscription or COPY capability is exposed. Errors are translated to categorical results without retaining SQL, parameters, driver objects or credentials.

Use `.raw()` for **every** row-producing query and `fetch_types: false`. Ordinary object/values results invoke generated row decoders after 16 rows; they are not an approved exception to SEC-1. Raw results bypass that code path. SQL text/identifiers stay code-owned, values are parameterized, rows are explicitly decoded/projected, and integers retain exactness. Limit pool admission, statement/lock/operation duration and owner result size. Transactions reserve one connection; authorize, mutate, audit and record work on that connection, with explicit isolation and whole-operation retry ownership. A driver selection does not implement these owner invariants.

## Observed pre-addition tests

Local Node 24.16.0 with the exact published package: native fake-server tests reject premature ReadyForQuery and unsupported authentication without transmitting query bytes or crashing. An isolated PostgreSQL 16.15 instance, used only as supplemental local evidence, verifies TLS/SCRAM channel binding, rejects an untrusted CA and wrong hostname, executes a parameterized injection canary, uses one backend for a serializable transaction, cancels a running query and reuses the pool. A 100-row raw query with instrumented `Function` construction makes **zero** code-generation attempts. This is not selected-version integration, full adversarial protocol review, company activation or release acceptance.
