# REQ-AUDIT-010 — initial Wave-0 envelope boundary

2026-11-05, local macOS arm64 / Node 24.16.0. Implementation continues after delegated decisions #28–#30, recorded by commit `5074f59` and draft PR #240. The issue template, local event-reading guide, SEC-1/8/10/11, ledger envelope and SEC-085/089 rows, OWASP Logging data-exclusion/verification guidance and Fastify logging documentation were read before coding.

`src/audit/envelope.js` implements a pure, closed projector for `dread.audit.config_change` and `dread.audit.validation_failure`. It snapshots own primitive data without invoking getters or toJSON, rejects unknown fields and invalid required identity/correlation, fixes catalog policy/severity fields, validates outcome/reason pairs, and omits invalid optional context with its marker. Internal references use a deliberately restricted ASCII opaque-identifier alphabet; arbitrary human labels, Unicode prose, URLs and code are not accepted as references. Timestamps require exact millisecond UTC round trips; event IDs currently use the application's UUID-v4 generator contract. Complete JSON is capped at 8,192 bytes with a 4,096-byte envelope check before declared event extras. Logger/receiver additions are not yet implemented and must stay within the same total later.

Eight focused test groups pass: immutable snapshot/JSON consumer, catalog and unknown-field canaries, nonexecuting accessor/prototype/symbol rejection, required identity/provenance/operation fields, optional-context omission, identifier/date/UUID and injection boundaries, outcome/reason semantics, and nonrecursive health diagnostics with exact counter bounds. The restricted current catalog's maximum valid field sizes fit below the total record ceilings; tests do not claim to have reached an otherwise unreachable 8,193-byte valid record. No package was added. The new module has an explicit empty import allowlist; no guard was weakened.

Build, strict checked contracts, runtime/import guard, reviewed dependency graph, whitespace and dependency audit (zero reported advisories) passed. The combined local `node --test` suite passed **81 tests**. The first strict check caught use of a newer string API than the project's declared library target; it was removed without changing the target or suppressing the check. Test typing errors were fixed before the successful full check.

## Still incomplete

It does not emit events, configure Fastify request/error/child serializers, preserve INFO through a real sink, deduplicate conflicts, persist PostgreSQL audit, fence commits, monitor independent health or prove crash recovery. No runtime ledger row is promoted and Wave 0 has not passed. Actual producer/consumer, authority, cancellation, PostgreSQL and failure tests named by #106 remain required as their owners are implemented. No later-wave instrumentation is enabled.
