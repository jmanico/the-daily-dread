# Demo dependency verification — 2026-11-04

Scope: REQ-DEMO-010 (#232). The baseline package selections and their earlier review are in [DEPENDENCY_REVIEW.md](DEPENDENCY_REVIEW.md). This records the actual, narrower demo installation. No application backend packages were installed.

Exact direct pins: React and React DOM 19.3.1; esbuild 0.28.2; TypeScript 7.0.2; development-only @types/react and @types/react-dom 19.3.0, @types/node 26.6.6. Native platform APIs do not provide React/Node type declarations. Handwritten substitute declarations would miss contract errors; these small development-only packages supply the maintained upstream DefinitelyTyped contracts. No runtime router, state library, UI framework, HTML sanitizer, parser or provider SDK is added.

Registry names, repository fields, publishers and dependency ranges were checked live, alongside [DefinitelyTyped's React](https://github.com/DefinitelyTyped/DefinitelyTyped/tree/master/types/react), [React DOM](https://github.com/DefinitelyTyped/DefinitelyTyped/tree/master/types/react-dom), and [Node](https://github.com/DefinitelyTyped/DefinitelyTyped/tree/master/types/node) source manifests through the GitHub API. The types publisher is Microsoft's `types` account. React/React DOM and build-tool upstream releases agree with the previously reviewed same-day selections. The declaration packages are the current stable registry releases observed during this review; matching React 19 and Node 26 contracts is intentional. Development testing here uses Node 24.16.0, and does not establish Node 26.13.0 release acceptance.

The DefinitelyTyped repository is active and not archived; current updates/open issues and [security policy](https://github.com/DefinitelyTyped/DefinitelyTyped/security) were inspected. Its policy supports only the latest release and best-effort volunteer security response. These declarations add a continuing compatibility/update obligation; they do not execute in the browser. Latest versions require revalidation during upgrades rather than assuming future source compatibility.

Resolved local tree: 12 installed package instances. New declaration transitives are `csstype` 3.2.3 and `undici-types` 8.9.0, both MIT and declarations only. React DOM brings scheduler 0.28.0; esbuild and TypeScript bring their matching platform binaries. Other platform packages remain optional lockfile entries, not additional installed runtimes. Package manifests, scripts, file inventories and license/notice files were inspected. No lifecycle script ran (`ignore-scripts=true`); esbuild's postinstall was not needed for the package-manager-selected native binary.

License inventory: MIT except TypeScript and its native package (Apache-2.0, with NOTICE). Licenses are compatible with this MIT demo distribution. Installed development licenses/notices remain in their packages; the built artifact includes the MIT application/React/React DOM/scheduler notices and the three font licenses in `NOTICES.txt`. Fonts are the architecture-pinned upstream revisions; source URLs and SHA-256 hashes are retained in `demo/fonts/provenance.json`, and SIL OFL/copyright files are committed beside them. Regular, bold, italic and bold italic styles are bundled locally. No remote font requests occur.

Security checks against the actual tree: `npm audit --audit-level=high` reported zero known advisories; `npm audit signatures` verified 12 registry signatures and 6 attestations. These are observations, not proof of safety. Official [React](https://github.com/react/react/security/advisories), [esbuild](https://github.com/evanw/esbuild/security/advisories), [TypeScript](https://github.com/microsoft/TypeScript/security/advisories) and DefinitelyTyped advisory surfaces were checked. React's published Server Component advisories concern absent `react-server-dom-*` packages. esbuild advisories GHSA-gv7w-rqvm-qjhr and GHSA-g7r4-m6w7-qqqr were patched in 0.28.1; GHSA-67mh-4wv8-2f99 affects <=0.24.2. This demo uses 0.28.2 without the esbuild server or Deno module. No published TypeScript/DefinitelyTyped advisories were returned; absence is not assurance. The npm database scan covers the resolved tree represented in the lockfile.

The rejected runtime-auditor candidate remains uninstalled. TOOL-003/#26 remains open. Actual production CI capability/lint checks, container/runtime acceptance and the production browser matrix remain outstanding and are not replaced by this demo's tests.
